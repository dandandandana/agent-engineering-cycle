# B 红队 v1 定向复核

**结论：** 原 review-B 的 B1–B6 均已在 v1 的架构条款和验收合同中闭合；没有发现需要再加的架构阻断项。这里是合同审查，不是能力证明。授权来源、QA 驱动、快照权限、进程锁和 Hook 行为仍须按 P0/AC 做宿主验证；本轮不要求现在运行 Host PoC。

| 原发现 | v1 处置 | 定向复核 |
|---|---|---|
| **B1 QA 身份与 fresh context 可由字段伪造** | `design-v1.md` §8 将执行事实交给 QAAdapter，禁止报告字段铸造身份；分别记录身份、输入交付、终态等保证维度，缺项不能宣称独立通过。AC-08/09 验伪造、继承输入和真实交付。 | **规则已闭合；能力待 P0。** 主 Agent 仍负责 QA 语义裁决，程序只证明可观测的 actor/输入/终态事实。 |
| **B2 批准来源与动作权限不明** | §7 将 ActionGrant 与 RequirementDecision 分离；精确绑定宿主事件、cycle、Delta/动作范围；来源观测与语义解释分开。AC-03/11/12 覆盖伪造来源、旧 Delta、R2 不扩写权限。 | **规则已闭合；来源待 P0。** Skill/主 Agent 判断原话语义是否批准具体变更，核心不能把该判断升级为程序认证。 |
| **B3 起止哈希无法排除 QA 期间 ABA** | §8 明确冻结为实际不可变副本，QA 读取该副本；纳入相关 dirty/untracked/config，无法完整捕获时失败/受限。AC-07 专测 A→B→A。 | **规则已闭合；交付与只读性待 P0。** PoC 需证明 driver 实际读副本、不能写入受验输入；未验证时不能接受为当前 Q。 |
| **B4 lease/CAS 可能只在进程内生效** | §3、§9 规定同工作区跨进程 LocalStore 租约，begin、CAS、pending 和发布处于同一临界区，并限定已验证本地文件系统。AC-02 双进程并发验收。 | **规则已闭合；平台行为待 P0/P1。** 网络盘/云同步明确不默认支持。 |
| **B5 重试可能重放副作用，或未知结果永久含混** | §6、§9 定义稳定 request_id/摘要、同请求查旧操作、改参拒绝、未知 pending 阻止换 ID 重跑，并区分启动/终态/采集/清理/结算事实。AC-04/05/06 覆盖重试、崩溃切点和不重放。 | **规则已闭合；故障切点待 P1 自动验收。** 在未知时保持 unfinished 是正确结果，不要求猜测真实效果。 |
| **B6 Stop 可能重复续跑** | §11 每个 host turn 最多一次；同一 cycle revision+action 不重复 ticket；无新许可/不新鲜/不可判定/阻塞时不 block。AC-15 覆盖连续 Stop、跨 turn、blocked 和缺 turn flag。 | **规则已闭合；Hook 语义待 P0。** 未验证 turn/ticket 关联时只提示，不续跑。 |

## 仍需实验，不构成当前架构缺陷

- **DecisionAdapter：** P0 核实目标宿主能否把真实用户决定和自动续跑/普通文本区分开，并将来源关联到精确 Delta 或 ActionGrant（§7、AC-11/12）。只拿到模型表单或普通文本时保留 `reported/unknown`；来源可验证也不证明语义判断正确。
- **QA driver：** P0 验证真实执行身份、输入交付、只读副本、权限、终态和输出完整度（§8、AC-07/08/09）。任一必需维度不可得就保持 unavailable/未就绪，不用 SoL 现有代码或静态契约替代。
- **本地 Host/存储：** P0/P1 按目标文件系统验证跨进程锁、崩溃恢复、请求去重和归档故障点（§9、AC-02/04/05/06），并验证实际 Hook 的 turn/continuation 行为（§11、AC-15）。失败时保留限制，不扩大支持平台声明。

未发现新的触发→失败→影响链需要改写架构。SoL 只作为设计参考；本复核没有修改 SoL、运行测试或调用外部模型。
